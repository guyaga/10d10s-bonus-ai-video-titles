# Hebrew title fonts: full TTF files

The three Hebrew faces the skill uses, as complete desktop fonts. They're SIL Open Font License (see OFL-*.txt), from Google Fonts.

| File | Use it for |
|---|---|
| SuezOne-Regular.ttf | premium, film, luxury and real-estate headlines (serif display) |
| Karantina-Bold.ttf / -Regular / -Light | loud social stomp, sport, news and food (condensed display) |
| SecularOne-Regular.ttf | captions, HUD labels, UI, lower thirds and body text |

- **Renders:** the kit renders with the matching web fonts (`../*.woff2`). These TTFs are for everything else: install
  them on your machine for After Effects, Premiere, Figma or Canva, or use them for Hebrew text drawn with PIL in
  generated images (PIL's default font draws empty boxes for Hebrew).
- **₪:** Karantina draws a normal ₪. Suez One and Secular One draw ₪ as a stylised "שח" (no gershayim), so write ש״ח with those two.
